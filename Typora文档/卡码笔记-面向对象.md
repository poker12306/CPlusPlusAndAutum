**卡码笔记——面向对象**

**Q1: 拷贝构造函数参数为什么必须是 const 引用？**

如果是值传递，调用拷贝构造时又要拷贝实参，就无限递归了。加 const 是为了能接受常量对象和临时对象。

- ==为什么是引用，不引用为什么会发生无限递归==

如果我们的拷贝构造是这个样子：

```c++
class Person {
public:
    Person(Person other) {
        // ...
    }
};
```

当我们要调用的时候，基本代码如下：

```c++
Person p1;
Person p2(p1);
```

当p2(p1)时，相当于调用Person other = p1;此时other对象本身也需要去执行拷贝构造，而Person p2 = p1这一步本身也是在调用拷贝构造，因此就会陷入无限递归。

- ==关于移动构造函数以及左值和右值的关系==

```c++
int a = 10;
int b = a + 20;
```

在这两行代码中，a和b都是左值，a+20是右值。左值意味着有一块存在的地址空间，而右值只是一个临时的。

```c++
int a = 10;
int& ref1 = a;
```

同时，这里又有一个细节。左值引用的概念就是针对一块已经存在的地址空间。而右值引用就是针对临时而言，也就是右值。

```c++
std::string a = "hello";
std::string b = std::move(a);
```

在这两行代码中，std::move(a)的作用是将一个**左值**转换为**右值引用**，从而允许后续调用移动构造/移动赋值。

并且，移动构造函数的形式如下，也因为其要修改所传入对象的指针指向，因此**不能加const**

```c++
class MyString {
    char* m_data;  // 指向堆内存的指针
    size_t m_size;
public:
    // ✅ 正确的移动构造（不加 const）
    MyString(MyString&& other) noexcept 
        : m_data(other.m_data), m_size(other.m_size) {
        // 关键一步：必须把 other 的指针置空！
        other.m_data = nullptr;  
        other.m_size = 0;
    }
};
```
